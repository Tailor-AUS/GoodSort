# The Good Sort

Scan eligible cans and bottles at home in Brisbane. Earn a 5¢ sorting credit each. When a suburb has about 1,000 scanned containers, bag out — a driver takes them to a refund point.

The 5¢ is a sorting credit, not the 10¢ Containers for Change refund. This is not a refund point, and a driver trip is not booked until that suburb has the volume for one run.
